# The Eats — Secunda

Responsive restaurant website for The Eats in Secunda, Mpumalanga.

## Included

- Responsive desktop, tablet and mobile layout
- African home-style food menu
- South African drinks category
- Table reservation form
- GitHub Pages-ready static site

## Run locally

Open `index.html` in a browser, or run:

```powershell
py -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

Publish the repository from **Settings → Pages**, using the `main` branch and the repository root folder.
